A1  REACHABLE RANGE — enumerate every score the function can return
------------------------------------------------------------------------
  distinct reachable scores    : 113
  junk-varied challenge grid   : 113 distinct, 0 not in the lattice above
  minimum                      : 0.0000
  MAXIMUM                      : 0.9600
  the source clamps with Math.min(..., 1)
  does that clamp ever engage? : NO — it is dead code

  The weight blocks sum to 0.96, not 1.00. A perfect extraction — every
  field present, three well-formed agents, a nested parent, a classified
  collision with a trough signature, all three suppression fields, and a
  verdict with reasoning — scores 0.9600 and can never score higher. The
  metric is not on a [0,1] scale despite being clamped to one and being
  read as a fraction. Any downstream consumer that treats 1.0 as the
  ceiling is calibrated against a point the function cannot reach.

A2  CEILING — how many agents does the score actually look at?
------------------------------------------------------------------------
    1 well-formed agents -> 0.7600
    2 well-formed agents -> 0.8600
    3 well-formed agents -> 0.9600
    4 well-formed agents -> 0.9600
    8 well-formed agents -> 0.9600
   30 well-formed agents -> 0.9600

  identical from 3 upward       : YES
  Math.min(nWf, 3) is a hard ceiling: a run that names thirty interacting
  agents and a run that names three score the same. Every agent past the
  third carries zero bits. On an Observer docket — the stated use case,
  institutional capture with many nested parties — three is not a lot.

A3  GAMEABILITY — is the score measuring modelling, or form-filling?
------------------------------------------------------------------------
  rich reading (3 agents, real content) : 0.9600
  VACUOUS   ("." in every field)        : 0.9600
  deep but narrow (1 agent, precise)    : 0.3333

  rich == vacuous, exactly?             : YES   (delta 0.000000)
  vacuous beats the deep reading by     : 0.6267  (2.88x)

  Every predicate in the scorer is a presence test — !!b.name, .length
  >= 1, Boolean(field). None of them reads content. So the score is a
  measure of SCHEMA COVERAGE, not of modelling quality, and the two are
  not the same variable. That matters more here than it would elsewhere:
  the producer is an LLM asked to fill this exact schema, and filling a
  schema is the one thing an LLM will do whether or not the material
  supports it. The extraction prompt says "do not invent structure it did
  not infer" — the scorer pays for inventing it anyway.

  The direction of the bias is the problem. If completeness is really a
  proxy for schema-filling eagerness, then a correlation with downstream
  fidelity is exactly what you would ALSO see if eager runs were simply
  the runs on richer dockets. The claim needs the confound ruled out;
  nothing in this repo rules it out.

A4  RESOLUTION — how finely can this score rank ten cases?
------------------------------------------------------------------------
  distinct values reachable at all      : 113
  distinct values in the plausible band : 75
  that band spans                       : 0.2533 .. 0.9600


  P(at least one tie among n=10)        : 0.4658   under a UNIFORM draw
  That figure is a LOWER BOUND, and deliberately so. The extractor does
  not sample the band uniformly — an LLM told to fill a schema fills most
  of it, so the realised distribution is bunched near the top and ties are
  strictly more likely than this. What the number establishes is that ties
  are not a hypothetical: even at their least likely they occur about 47%
  of the time. A Spearman rho is a statistic on RANKS, and ties inflate or
  deflate it depending on how they are broken. The reported +0.61 is quoted
  to two decimals with no tie correction stated and no n=10 table to
  inspect, so its tie structure is unknown and its third digit is not
  recoverable from anything in this repository.

A6  THE INTERVAL, AND THE "7x LIFT"
------------------------------------------------------------------------
  Pearson  se = 1/sqrt(n-3)      = 0.37796   (WRONG statistic here)
  Spearman se = 1.06/sqrt(n-3)   = 0.40064   (Bonett & Wright)

  rho = +0.61, n=10  ->  95% CI [-0.076, 0.904]   (Pearson se would say [-0.032, 0.896])
  rho = +0.08, n=10  ->  95% CI [-0.608, 0.699]   (Pearson se would say [-0.579, 0.676])
  the two intervals overlap over    : [-0.076, 0.699]
  does the +0.61 interval contain 0 : YES

  "+0.61 vs +0.08 — a 7x lift" is a ratio of two point estimates whose
  intervals both straddle zero and overlap each other across most of
  their length. A ratio of two quantities that may both be zero is not a
  lift; 7x is an artefact of dividing by a small noisy denominator. Had
  the trajectory figure landed at +0.02 the same data would have read as
  "a 30x lift", and at -0.01 the ratio would have changed sign.
