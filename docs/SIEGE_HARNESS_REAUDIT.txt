F1  NO SELF-STAMP. The harness wrote a results file with no commit id and no
    dirty flag, so its numbers could not be tied to a tree state.
    FIX: git rev-parse HEAD + git status --porcelain in the header.

F2  WRONG CAUSAL ATTRIBUTION — CONFIRMED BY A VERBATIM READ OF src/hyper.ts.
    The 1st pass blamed the depth collapse on "the clamp interacting with
    placeFeatures' n>1 branch". It is not an interaction. ripVector already
    clamps to ‖f‖ ≤ 1 (hyper.ts:198), so placeFeatures' n>1 branch is
    UNREACHABLE from this path — it always takes the else branch and scales
    by 0.9. The clamp at hyper.ts:198 destroys the radial coordinate BY
    ITSELF. Same number, wrong mechanism; a wrong mechanism sends the fix to
    the wrong line.
    FIX: attribution corrected, and an α-scaling counterfactual added that
    distinguishes "the variation is absent" from "the variation is discarded".
    MEASURED: at α=1 depth range is 0.000000; at α=0.1 it is 0.930008. The
    radial signal EXISTS and is being thrown away.

F3  SINGLE-ε, SYNTHETIC-ONLY TORUS TEST. The 148× tear was measured at one
    ε on one hand-built index. A tear that only appears at ε=0.01, or only on
    synthetic input, is an artefact.
    FIX: ε swept over six decades (1e-1…1e-6) plus a real-pamiIndex arm.
    MEASURED: tear holds at ≥16.7× across all six decades and reproduces on
    real indices (min 116.3, median 123.0, max 145.0).

F4  DEPENDENT-PAIR COHEN'S d. 1200 within- and 3750 between-family distances
    over only 100 indices: each index appears in many pairs, so the "n" in
    any standard error is a fiction. The 1st pass reported d as though the
    pairs were independent.
    FIX: d relabelled [DESCRIPTIVE ONLY] with the limitation stated inline,
    and supplemented by a statistic with ONE TRIAL PER INDEX — leave-one-out
    nearest-neighbour family purity, with Wilson 95% intervals.
    MEASURED: native 95/100 = 0.950 [0.888, 0.978]; bridge 81/100 = 0.810
    [0.722, 0.875]. Chance = 0.250. The loss is real at 95%.

F5  EUCLIDEAN CENTROID IN A HYPERBOLIC SPACE. B4 averaged coordinates
    arithmetically. That is not the centre of mass of points in the ball.
    FIX: Fréchet/Karcher mean by Riemannian iteration on the SHIPPED
    mobiusAdd, reported against the Euclidean centroid and the origin on the
    same Σd² objective, so the reader can see which centre actually wins.
    MEASURED: Fréchet ‖c‖ = 0.4566 (mean d² 1.8110) beats Euclid ‖c‖ = 0.5650
    (mean d² 1.9409). Origin: mean d² 3.2400.

F6  A HARNESS THAT CANNOT FAIL. Constant exit 0 — unwireable into CI.
    FIX: DEFECTS ledger + process.exit(DEFECTS.length ? 1 : 0).
    MEASURED: exit 1, 7 adverse findings.

G   ASSERTED THE DIRECTION OF ITS OWN CORRECTION — FOUND BY RUNNING F5, NOT
